# DuckPhp\Core\CoreHelper

A "Helper collection" for direct use by global functions / view templates: one-stop convenience wrappers for common HTML/JSON/language/URL output.

## Introduction

`CoreHelper` is the facade where the framework collects "common small features" as a set of **static convenience methods**: most `__h`, `__l`, `Clone…`-style global functions (see `Core-Functions`) ultimately go through it; business code also often calls `CoreHelper::H()`, `::Json()` etc. directly.

- Output and encoding: `H` (HTML escaping), `Hl` (translate then escape);
- language: `L`, `LangText`;
- JSON: `Json` (with `JSON_UNESCAPED_UNICODE|JSON_NUMERIC_CHECK` by default, plus pretty-printing under debug);
- URL/Domain/Res (forwarded to `Route`);
- view: `Display` (forwarded to `View`);
- debugging: `var_dump/VarLog/TraceDump/DebugLog` (effective only under debug, forwarded to Logger);
- environment/Request: `IsDebug/IsHiddenDebug/Platform/IsAjax`;
- business-friendly: `ShowJson/Show302/XpCall/PhaseCall/BusinessThrowOn/ControllerThrowOn`.

Most are set up as static shells forwarding to the **corresponding instance methods** `_Xxx`; changes can be made just by (overriding) the instance or its related handlers (html_handler, lang_handler).

## Class info

- Namespace: `DuckPhp\Core`
- Declaration: `class CoreHelper extends ComponentBase`
- Often pre-built by `App` with `EXT_SKIP_INIT` (see Core-App's initComponentsOfRoot).

## Options

This class has no options of its own (its behavior relies on these App settings):

| Factor | Description |
|---|---|
| `html_handler` | When set, `_H` uses it instead of the default `htmlspecialchars`. |
| `lang_handler` | See `App::lang` — `L/Hl/LangText` go through it. |
| `exception_for_business/controller/project` | Used when `Business/ControllerThrowOn` don't specify one. |
| `exception_map` | Class-name mapping applied before throwing (`original class => replacement class`); all three `*ThrowOn` consult it first. |
| debug (`App::_IsDebug()`) | Decides the Debug output family, IsDebug, Json pretty-printing, etc. |

## Usage

```php
use DuckPhp\Core\CoreHelper;

echo CoreHelper::H($username);            // HTML escaping
echo CoreHelper::L('hello');              // translation
echo CoreHelper::Json(['ok'=>1]);         // json string (unicode/numbers unescaped + pretty-printing choice)
echo CoreHelper::Url('user/show');
CoreHelper::ShowJson(['ok'=>true]);       // json header + echo
CoreHelper::IsDebug();
```

The corresponding global functions (Functions layer) are in [Core-Functions](Core-Functions.md).

### Business/Controller throwing

```php
CoreHelper::BusinessThrowOn($userId === null, 'no user');
CoreHelper::ControllerThrowOn($tokenNotOk, 'bad token', 400);
```

## Configuration example

```php
// change HTML handling or take over the language (app options)
$options['html_handler'] = function ($s) { return htmlspecialchars($s, ENT_QUOTES); };
$options['lang_handler'] = function ($s, $a) { return my_t($s, $a); };
```

## Caveats

1. HTML escaping `H` is the default behavior; when there is an html_handler, yours is used.
2. The Debug utilities (var_dump/VarLog/TraceDump/DebugLog, Json pretty-printing in ShowJson) stay silent / un-prettified when not in debug, avoiding production information leaks (turn on debug when you need development debugging).

## Methods

> The static shells below mostly forward to same-named `_Xxx` instance-layer methods; business code just uses the shells.

### Public static methods

    public static function H($str)
Returns $str HTML-entity-escaped (arrays are H'ed recursively); html_handler takes priority when set.

    public static function L($str, $args = [], $fallback = null)
Translation: delegates to `App->_lang` (goes through it when lang_handler is configured).

    public static function Hl($str, $args = [])
Combined escape shell: L first, then H.

    public static function LangText($desc, $args = [])
Parses `[[key|fallback]]` segments via Lang; delegates to App::langText().

    public static function Json($data, $flags = 0)
json-encodes, adding UNESCAPED_UNICODE|NUMERIC_CHECK; adds JSON_PRETTY_PRINT under debug.

    public static function Url($url = null)
Returns an in-site URL generated by `Route` (delegates to `Route::_()->_Url`).

    public static function Res($url = null)
Static resource URL (delegates to `Route::_()->_Res`).

    public static function Domain($use_scheme = false)
Current domain (delegates to `Route::_()->_Domain`).

    public static function Display($view, $data = null)
Outputs a view directly (delegates to `View::_()->_Display`).

    public static function var_dump(...$args)
Echoes `<pre>var_dump</pre>` under debug.

    public static function VarLog($var)
Logs `var_export` under debug (Logger).

    public static function TraceDump()
Echoes the current exception's trace under debug.

    public static function DebugLog($message, array $context = array())
Logs message+context under debug (Logger::debug).

    public static function Logger($object = null)
Returns (or injects with $object) the logger — straight through to `Logger::_()`.

    public static function IsDebug()
Whether debug (App::_IsDebug).

    public static function IsHiddenDebug()
The real debug check.

    public static function Platform()
Platform identifier (App::_Platform).

    public static function IsAjax()
Detects X-Requested-With: XMLHttpRequest.

    public static function ShowJson($ret, $flags = 0)
Sets the JSON response header then echoes Json($ret); usually the (Ajax/API-facing) output.

    public static function Show302($url)
In-site redirect: writes `Location`, cross-origin urls are ignored outright (PHP_URL_HOST).

    public static function XpCall($callback, ...$args)
"Exception-confined" call: returns the ex when an `Exception` is thrown, otherwise the result.

    public static function PhaseCall($phase, $callback, ...$args)
Executes under the given Phase and returns afterwards, then switches back to the original Phase.

    public static function ChildCall($phase, $callback, ...$args)
Executes the callback under the given "child app Phase", then switches back to the original Phase.

    public static function ProjectThrowOn(bool $flag, string $message, int $code = 0, $exception_class = null)
When `$flag` is true, throws a "project exception" (class taken from `exception_for_project`, mapped through `exception_map`).

    public static function BusinessThrowOn(bool $flag, string $message, int $code = 0, $exception_class = null)
When $flag is true, throws a business exception (or exception_class).

    public static function ControllerThrowOn(bool $flag, string $message, int $code = 0, $exception_class = null)
Same as above but for the controller layer; takes exception_for_controller→project→Exception.

    public static function Show404()
Turns into "call App::On404()" (the root's 404 fallback).

### Instance methods (the _X counterparts)

    public function _H(&$str)
HTML escaping / array recursion implementation.

    public function _L($str, $args = [], $fallback = null)
The actual translation entry (App::lang).

    public function _Hl($str, $args)
`_L(...)` then `_H(...)`.

    public function _LangText($desc, $args = [])
App::langText forwarding.

    public function _Json($data, $flags = 0)
json_encode with the flags logic.

    public function _VarLog($var)
Under the debug gate, hands var_export($var,true) to Logger::debug.

    public function _var_dump(...$args)
Under the debug gate, echoes `<pre>var_dump</pre>`.

    public function _TraceDump()
Under the debug gate, rebuilds an empty exception trace and outputs `<pre>`.

    public function _DebugLog($message, array $context = array())
Under the debug gate, logger debug ($context). Returns false when not debug.

    public function _IsDebug()
Forwards to App::_IsDebug.

    public function _IsHiddenDebug()
Forwards to App::_IsHiddenDebug.

    public function _Platform()
Forwards to App::_Platform.

    public function _IsAjax()
Reads `HTTP_X_REQUESTED_WITH`.

    public function _ShowJson($ret, $flags = 0)
header json + echo.

    public function _Show302($url)
In-site redirect only.

    public function _XpCall($callback, ...$args)
Catches Exception and returns the exception-or-result implementation.

    public function _PhaseCall($phase, $callback, ...$args)
Reversible implementation around the phase-switching callback.

    public function _ChildCall($child_app, $callback, ...$args)
Switches to the given child app (`App::toThisChild`), runs the callback, then switches back to the original Phase.

    public function _ProjectThrowOn(bool $flag, string $message, int $code = 0, $exception_class = null)
The project exception path (default `exception_for_project`, mapped through `exception_map`).

    public function _BusinessThrowOn(bool $flag, string $msg, int $code = 0, $exception_class = null)
impls; the business exception path.

    public function _ControllerThrowOn(bool $flag, string $msg, int $code = 0, $exception_class = null)
The controller throw path.
